# 真实录屏测试纪要

测试素材（两段同一门课，电脑内录，1920×1080）：

1. `lecture-a.mp4`（60 分钟）
2. `lecture-b.mp4`（62 分钟）

## 复测：准确率优先的当前方案

### OCR：RapidOCR + Apple Vision 互补（`--engine hybrid`）

- `auto` 现在优先解析到 `hybrid`：RapidOCR（PP-OCR ONNX）负责正文，Apple Vision 补小字/低对比度行。
- 两段视频共 54 帧，除黑屏/纯图外全部有文字；识别结果写入 `slides.json` 的 `lines` / `text`。
- **正文一个字都不改写**。标题修复只动 `title`，原值留在 `title_ocr` 供审计。

### 艺术字标题：三层兜底

| 层 | 做法 | 效果 |
|---|---|---|
| 1 | 跨页同标题投票（只统计 `slide/blank/unknown` 页） | 视频 1 的「核心问提是什么?」「核心问提是什?」→「核心问题是什么」 |
| 2 | 标题词频 / 正文一致性校验（jieba 词频，可选依赖） | 挡住「天写动物最天的这别是什么?」这类乱码标题 |
| 3 | 本地 VLM 读图（Ollama `qwen3-vl:2b-instruct`） | 读对「（一）为什么要学习」「（二）核心概念是什么」等艺术字 |

VLM **不是一读就换**。2B 模型有两个已复现的毛病：

- 无标题页会退化成「（一）」；
- 给好标题硬加编号（「某主题的三个层次」→「某主题的三个层次（一）」）。

`_apply_vlm` 的接受规则：OCR 标题太短/是正文长句才换；VLM 只是给 OCR 加编号或标点时保留 OCR；
VLM 明显更通顺（词频分高 0.8 以上）或 OCR 含词典里没有的错词时才换。VLM 说 `has_figure=true`
但没给出 `figure_note` 时，不把它当图表页，避免装饰图误报。

### 页面分类：考勤平台不是课件

视频 2 开头老师打开了「电子考勤管理平台 / 课堂点名」页面，和课件一样是全屏 16:9，
最初被误判成 `slide`，VLM 于是读出「（一）」这种标题。加入界面特征词
（`电子考勤管理平台`、`课堂点名`、`统一入口`、`考勤管理平台` 等）后，这些页归为 `browser`，
不再进笔记。视频 2 的分类结果：`slide 15 / browser 11 / blank 3 / desktop 2 / editor 1 / ui 1`。

### ASR：默认 medium，提示词自动从课件标题拼

3 分钟课堂片段（含学生发言、学科名词）实测：

| 模型 | 转写耗时 | 表现 |
|---|---|---|
| `small` | 32 秒 | 快，但专有名词错得多，只适合草稿 |
| `large-v3-turbo` | 41 秒 | 快，但句子更碎（「梦子」「课长虚论」） |
| `medium` | 84 秒 | 最连贯（专业术语、课堂讨论基本对），默认 |

M2/8GB 上 medium 约 2.1 倍速，60 分钟课 28–40 分钟。`run_asr` 不传 `initial_prompt` 时，
自动从 `slides.json` 的课件标题拼一条（最多 16 个标题、220 字），也可用
`--initial-prompt` / `CVN_ASR_PROMPT` 覆盖。

### 知识点提取：宁可少而准

旧的 n-gram 启发式在人文类课上会产出大量垃圾（「并且咱们」「虽然咱」「然后呢」「这个啊」）。
现在加了四道闸：

1. 知识点名必须能在课件正文里找到（挡住只在口语里出现的半句）；
2. 学分/学时/考试/作业/考勤/教师/选题范围等事务信息不进 `knowledge.md`；
3. 页面最上面的短行、标题 OCR 变体、带句读/括号的碎片不当知识点；
4. 页标题本身作为概念来源（「某概念的起源」「某问题的答案」），
   说明优先取讲解里的解释句，其次取课件里的定义/副标题，找不到就如实写「见第 N 页课件」。

视频 1 复测：知识点从 41 条降到 5 条（全部可核对），重点 13 条；`knowledge.md` 不再出现上述垃圾词。

## 已知限制

- **ASR 同音字仍在**：`比试`→`笔试`、`学识`→`学时`、`并卷/笔卷`→`闭卷`、`刑事动课`→`形势与政策课`、
  `券案室/居然使`→`教研室`。medium 能修掉一部分，但没有术语表/上下文纠错，不能保证全对。
- **本地 7B 文本模型不可行**：M2/8GB 上 `qwen2.5:7b` 做逐页知识点抽取，10 分钟超时且明显换页，
  放弃这条路；2B VLM 只适合读标题/图表，不适合长文本推理。
- **VLM 图表说明会误报装饰图**：例如纯色背景上的校徽会被描述成「建筑图案」。`figure_note` 是提示，
  不是事实；用户仍应对照 `slides/` 原图。
- **知识点召回偏低**：为保证准确率，当前只收课件上有的概念，老师口头补充但课件没写的
  不会自动进清单。需要更全的清单时，先补课件/讲义，而不是让模型编。

## 复现命令

```bash
# 建议用持久环境，避免每次装 RapidOCR / faster-whisper
~/.venvs/cvn/bin/python scripts/course_kit.py probe

# 课件 OCR（视频 1；视频 2 把 --out 换掉）
~/.venvs/cvn/bin/python scripts/course_kit.py frames \
  --video "<视频>" --out /tmp/lab --interval 3 --pick last
CVN_OCR_PYTHON=~/.venvs/cvn/bin/python \
  ~/.venvs/cvn/bin/python scripts/course_kit.py ocr \
  --out /tmp/lab --engine hybrid --vlm --force

# 语音转写（默认 medium，提示词自动取课件标题）
~/.venvs/cvn/bin/python scripts/course_kit.py asr \
  --video "<视频>" --out /tmp/lab --model medium

# 对齐 + 笔记
~/.venvs/cvn/bin/python scripts/course_kit.py merge --out /tmp/lab
```

注意：

- `--interval 3 --pick last` 是这段素材调出来的；`--pick last` 对**有动画的 PPT** 很关键。
- `av==16.0.1` 要钉住；`av==19` 会让 faster-whisper 报
  `open() got an unexpected keyword argument 'metadata_errors'`。
- HuggingFace 直连不通时：`export HF_ENDPOINT=https://hf-mirror.com`。

# 第二轮：接手既有改动后的修 bug 记录

opencode 加了 RapidOCR（中文首选）+ 本地 VLM（读艺术字标题），把上一轮
"艺术字标题认不准"的核心难题解决了。实测 RapidOCR 对同一张课件：

    Vision   : 20苯颗椁思分苏为z苏分，总苏时为32颗时      conf 0.30
    RapidOCR : 本课程总学分为2学分，总学时为32课时          conf 0.98

但它的改动也引入了 4 个 bug，这轮全部修掉：

## 1. 换 OCR 引擎后 `classify` 误杀正常页

`classify_page` 的 blank 判据原来是「内容行 ≤1 且总行 ≤3」。
两个引擎的**框粒度不同**：Vision 把一行拆成好几个框（含时间戳），
RapidOCR 倾向把整行合成一个框。于是「只有一行但内容是 22 字完整句子」的
课件页被判成 blank。

修法：改成看**文字总量**，不只看行数。
`n_content<=1 and content_chars<=8 and n_all<=3` 才算 blank。

## 2. `_title_desc` 参数传错（会直接崩）

```
AttributeError: 'int' object has no attribute 'get'
```
`page["segments"]` 存的是**字幕下标列表**（`[0,1,2]`），
而 `_speech_units(page, segments)` 要的是**全量 segment 字典列表**。
opencode 在 `_title_desc` 里直接传了下标列表。

修法：给 `_title_desc` 增加 `segments` 参数，由 `build_knowledge` 透传。

**教训**：`page["segments"]`（下标）和 `segments`（全量）名字太像，
很容易混。改这块代码时务必确认传的是哪个。

## 3. 翻页阈值写死导致纯 PPT 视频被吞成一页

上一轮我按真实录屏把 `DEFAULT_CHANGE_RATIO` 从 0.02 提到 0.10。
但换成纯 PPT 视频后（白底换页时大部分像素仍是白的），翻页 ratio 只有
0.022~0.030，全被当成"同页"，整段课变成 1 页。

两个素材的 ratio 分布：

| 素材 | 相邻帧 ratio 中位 | 翻页时 ratio |
|---|---|---|
| 纯 PPT 视频 | 0.0000 | 0.022 ~ 0.030 |
| 真人录屏 | 0.0000 | 0.19 ~ 0.94 |

修法：**自适应阈值**（`media.adaptive_ratio_threshold`）——
先算本段所有相邻帧的 ratio，取非零值的 p85 作为"明显变化"的代表，
阈值 = 该值 × 0.35，夹在 [0.008, 0.10]。
`--change-ratio` 默认不填即自适应，填数值则强制。

实测：纯 PPT 自动取 0.0106（→4 页，正确）；录屏自动取 0.1000（→21 页，与人工一致）。

## 4. 短页合并阈值同样不能写死

`DEFAULT_MIN_PAGE=12` 会把 50 秒的短课（每页 12 秒）整段吞掉。
改成按本视频平均页长的 40% 自适应，夹在 [3s, 12s]。

## 5. 划重点混入口语铺垫句

原来的打分只要命中"所以/因为"(+2) 再凑一分就过阈值，于是
「所以某某说到呢」「所以也就说,对相关的一些内容啊」这类句子全进了重点。

修法：`notes._has_substance()` 信息量守卫，要求至少满足一条：
- 命中课件术语**且术语有份量**（≥4 字，或占实词多数）
- 去掉口语连接词后实词 ≥6 字，且**实词占比 ≥50%**
- 定义/结论句式且实词 ≥4 字

注意第 1 条的坑：只判「是否命中术语」不够——
「所以某某说到呢」也含人名，但那句的实际内容是"所以…说到呢"。

## 新增 `cvn/layout.py`：按版面重建正文

OCR 输出的是一堆**视觉行**，不是文章。直接按行拼接会得到：

```
2026年09月
17:02:09
大字意味看什么
某类课程
概念甲·概念乙·概念丙
授课教师：某某
)(D)()(品)((
```

用户要的是「PPT 上写了什么」：

```
核心问题是什么
某类课程
概念甲 · 概念乙 · 概念丙
授课教师：某某
```

`layout.rebuild()` 做四件事：

1. **去页眉页脚**：日期、时间戳、星期、机房号水印、页码、校名、纯符号残渣
2. **接回断行**：PPT 里一句话常被排版切成两行
3. **识别层级**：heading / subhead / bullet / body / quote / cite
4. **按版面排序**

### 断行拼接的分寸（踩了很多坑）

一开始用"上一行没结尾标点就接"，结果把 6 条独立要点揉成一大段。
最终判据按优先级：

- 下一行是**独立条目**（项目符号 / `考勤：10分` 这种标签行 / 短句）→ 绝不接
- 上一行**引号未闭合** → 必须接（经典文献摘录常被切成 3 段）
- 上一行以 `，、；` 结尾，或下一行以标点开头 → 接
- 版面证据：两行紧邻（间隙 < 半行高）且上一行够长 → 接

### 引文 vs 引号强调

`"某概念之名"` 是 PPT 用小标题（引号强调），不是引文；`"若……之知……"` 这类才是引文。
判据：整行被引号包裹 **且** 长度 ≥40 或含句子标点。短促的引号短语算 subhead。

### 一页只允许一个 heading

否则字号大的行会被全标成标题，`核心问题是什么` / `一组数据…` / `更重要的是…`
三个都加粗，层级就没了。后面的大字号行降为 subhead。

## ASR 幻觉：两个必须挡住的坑

`auto_initial_prompt`（用课件标题喂 whisper）方向很好，但踩了两个坑：

### 坑 1：whisper 把提示词当语音输出

录屏开头常是静音（在调设备），whisper 会**把提示词当成听到的内容吐出来**：

```
initial_prompt = "本课程总学分为2学分,总学时为32课时，核心问题是什么…"
segments[0]    = "本课程总学分为3学分,总学时为32课时,"   ← 凭空捏造，还改了数字
```

`_drop_prompt_leakage()`：片段字词有 ≥95% 来自提示词 → 丢弃。
这类片段覆盖率实测是 **1.00**（字字都来自提示词），很好认。

### 坑 2：长静音处 whisper 会"编"出超长片段

```
正常讲解片段：中位 3.0s / p90 7.0s / p99 21s
幻觉片段：    161s / 177s / 64s / 180s
```

差一个量级。`_drop_stretched_hallucinations()`：时长 > max(30s, 中位数×8) → 丢弃。

不剔这两类，前 7 分钟的编造内容会被当成老师讲课写进笔记，比不识别更糟。

## 跨页纠错：做了但默认关闭

想法是用「同一门课里高置信度的同句」修正低置信度的错字
（如 `核心问提是什么?` conf 0.84 vs `核心问题是什么?` conf 1.00）。

实现完发现**风险大于收益**：

- 用整页平均置信度时，纠错方向是反的（把错的当权威）
- 改成逐行置信度后，片段匹配又过于激进：
  `2026/` → `2025-2026聚焦建设更高水平平安中国 2025/`
  `幻灯片第142张` → `第190张`（数字被改错，信息失真）
- 收紧到「长度相同 + 差 1~2 个汉字 + 不碰数字英文」后，基本修不到东西

结论：`cvn/crossfix.py` 保留但 `enabled=False`。宁可留错字让用户对照原图，
也不要系统性地改写内容。

## 新增 `cvn/pdf.py` + `course_kit.py pdf` 子命令

```bash
python3 scripts/course_kit.py pdf --out out/<课程名> --title "课程名 · 第1讲"
```

产物 `课程笔记.pdf`（同时保留 `course.html`，改样式直接改它）。

**为什么走 HTML 而不是 reportlab**：中文排版、图片自适应、分级标题用 CSS 几行就够，
reportlab 要手算每个坐标。用本机 Chrome 无头打印，不需要 LaTeX / wkhtmltopdf。

PDF 结构：封面 → 目录 → 逐页（课件原图 + 版面还原文字，讲解折叠成灰字）→ 知识点一览 → 重点速览。

### 踩坑

1. **Chrome 无头打印很慢（62 秒）**。原因是在用你正在用的 Chrome 配置目录，
   Crashpad 上报超时在拖。加 `--user-data-dir=<临时目录> --disable-crash-reporter`
   后降到 15 秒。
2. **`export_for_pdf` 复用旧 aligned.json 导致 PDF 里没有重点**。
   用户可能先 `--skip-asr` 出课件版，之后补跑 asr 再出 PDF，
   但旧 aligned.json 里每页 speech 还是空的 → PDF 里重点 0 条。
   改成每次都重新 `align()`（几百毫秒，不值得省）。
3. **图片缺失时静默出无图 PDF**。现在会打警告。

## 第二段素材：VLM 成了刚需

这段录屏的标题是**艺术字 + 被时间戳遮挡**，RapidOCR 全错：

| OCR 结果 | VLM 结果 |
|---|---|
| 天写动物最天的这别是什么? | 人与动物最大的区别是什么？ |
| 人为仟要学习 | （一）为什么要学习 |
| `"天"是仟么?` | （二）"核心概念"是什么？ |
| `(如荷学以成大?` | （三）如何成人？ |

但 `_accept_vlm_title` 拒绝了 9/11 页。原因：
- 它依赖 jieba 判断"生僻词"，而**这台机器没装 jieba**，`_has_unknown_word` 永远 False
- 词频阈值 +0.8 太严

修法（不依赖 jieba）：
1. **生僻字判据**：GB2312 一级字库外的字占比 ≥15% → 认错了
2. **字重合度判据**：两边长度≥4、Dice 重合度 <0.75 → OCR 那段整体认错了
   （实测分界：「加编号」类 0.95+，「整体认错」类 0.55~0.67）
3. 长度门槛从 6 降到 4（「日天"是什么」只有 5 字）

结果：11 页标题被纠正，全部可读。

## 动画阶段合并的边界

第二段素材有 17 个课件页，但很多是**同一标题下的多屏内容**，不是逐条动画：

```
页18: 思想家甲（关于"成人"的一种观点）
页21: 思想家乙（关于"成人"的另一种观点）
```

两页标题相同、但**图像指纹完全不同**、内容 0% 重合 → **不是同一页的动画阶段，不该合并**。

所以最终保留 12 页，并在 PDF 里给连续同标题的页标「续」，
让读者知道这是同一主题的延续，而不是重复内容。

**教训**：合并动画阶段不能用"标题相同"一刀切，必须同时满足时间接近 + 内容相关。
宁可多留一页，也不要把不同内容揉在一起。

## ASR 幻觉守卫实测有效

第 2 讲转写时两个守卫都触发了：
- 剔除 4 条提示词幻觉（录屏开头静音，whisper 把 initial_prompt 当语音）
- 剔除 6 条超长幻觉（最长 180 秒，正常片段中位 3 秒）

不剔的话，前 3 分钟会被编造的"课程介绍"占满。
