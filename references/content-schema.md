# 讲义内容 JSON 的格式

`course_kit.py textbook --content <this.json>` 用它生成系统复习讲义 PDF。

## 顶层

```json
{
  "title": "课程名",
  "subtitle": "副标题（范围/主题）",
  "meta": {"course": "...", "scope": "...", "teacher": "...",
           "source": "...", "compiled": "..."},
  "preface": ["第一段…", "第二段…"],
  "chapters": [ ... ],
  "review": {"title": "复习要点", "blocks": [ ... ]}
}
```

## 章节与小节

```json
{"no": "第一章", "title": "章节标题",
 "leads": ["引言段（黄底引文框）"],
 "sections": [
   {"no": "1.1", "title": "小节标题", "blocks": [ ... ]}
 ]}
```

## block 类型

| type | 字段 | 渲染效果 | 用途 |
|---|---|---|---|
| `exam` | question, items[], standard | 考点框（金色标签 + 编号要点 + 标准表述） | **必背考点**，放每节开头 |
| `distinguish` | label, text | 辨析框（蓝色左边线） | 易混概念对照 |
| `para` | text | 普通段落 | 正文叙述 |
| `def` | term, text | 概念定义（灰底框 + 红色术语名） | 术语解释 |
| `quote` | text, cite | 经典引文（金字边引用块 + 右对齐出处） | 原文引用 |
| `explain` | text | 阐释（左侧细竖线缩进） | 对引文的解读 |
| `key` | text | 要点（黄底框，自动加「要点」标签） | 结论式提示 |
| `note` | text | 补充（灰底，自动加「补充」标签） | 讲义的增量说明 |
| `table` | headers, rows | 对照表（深红表头，隔行浅色） | 多维对比 |
| `figure` | src, caption | 插图（居中 + 编号图注） | 配图 |

`para` / `def` / `quote` / `explain` / `key` / `note` / `exam.items` / `exam.standard` 的文本支持 `**粗体**`。

## 考点块怎么写（这是「有考点」与「只讲了什么」的分界）

```json
{
  "type": "exam",
  "question": "如何理解「条件、过程、结果」三者的关系？",
  "items": [
    "「条件」是前提——它规定了后续发展得以成立的范围，本身不是目的。",
    "「过程」是转化路径——它不是线性推进，而是长期累积、逐层展开。",
    "「结果」是最终形态——它不是时间的自然终点，而是条件与过程共同作用后的成熟状态。"
  ],
  "standard": "三者构成一个闭环：条件是前提，过程是方式，结果是归宿。"
}
```

写作要点：

- **question** 用设问句，对应考卷上的问法（「如何理解…」「简述…」「为什么说…」）
- **items** 每条是一个独立得分点，编号由渲染器自动生成，不要自己写「1.」
- **standard** 是能直接抄到答卷上的标准表述，一到两句，收束该考点
- 一节的考点块放在 `blocks` 数组最前面（figure 之后），先看要点再看阐释

## 辨析块怎么写

```json
{
  "type": "distinguish",
  "label": "辨析：民本 ≠ 民主",
  "text": "传统「民本」主体是君主——是君主以民为本；现代「民主」主体是人民——是人民自己作主。前者是「为民作主」，后者是「由民作主」。"
}
```

用于处理**看起来像但实质不同**的概念对。放在相关正文附近。

## 写作约定

- **课件上有的**：直接写，不标注
- **课件上只有标题/要点、需要展开的**：写进 `note`（自动显示「补充」标签）
- 引文必须带 `cite`（课件上标了出处的，照抄）
- 语言用**教材式叙述**：不要出现「课件显示」「老师讲到」「本页」这类元叙述
- `review` 部分建议用一张 table 列考点索引，最后加一条 `key` 收束主线
